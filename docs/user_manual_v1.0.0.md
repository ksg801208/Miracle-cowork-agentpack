## 1. 제품 개요

### Miracle-Cowork AgentPack이란?

Miracle-Cowork AgentPack은 중소기업·스타트업·연구기관의 업무 문서 작성을 AI로 자동화하는 플랫폼입니다.  
**8개 업무 영역 · 57개 AI Agent**가 탑재되어 있으며, 입력 정보를 채우고 실행 버튼만 누르면 완성도 높은 한국어 비즈니스 문서가 즉시 생성됩니다.

### 주요 특징

| 특징 | 설명 |
|---|---|
| **즉시 사용 가능** | Mock 모드로 API Key 없이 바로 사용 가능 |
| **57종 문서 자동화** | 제안서·사업계획서·특허·회의록 등 전 범위 커버 |
| **프로젝트 관리** | 실행 이력과 저장 문서를 프로젝트별로 분류 관리 |
| **Markdown 다운로드** | 생성된 문서를 `.md` 파일로 저장·공유 가능 |
| **LLM 전환 가능** | Claude API Key 설정 시 실제 AI 생성으로 전환 |

### 활용 대상

- **사업기획 담당자**: 정부 R&D 공고 분석, 사업계획서, 제안서 작성
- **PM/프로젝트 매니저**: 회의록, 주간 보고서, WBS, 프로젝트 현황 보고
- **연구원**: 연구 제안서, 연구비 계획서, 최종 성과 보고서, 특허 출원 초안
- **개발자**: 요구사항 정의서, API 명세서, 테스트 케이스, 코드 리뷰 문서

## 2. 시스템 접속 방법

### 브라우저 접속

아래 주소를 브라우저 주소창에 입력합니다.

```
개발/테스트 환경: http://localhost:5173
운영 환경: 관리자로부터 제공받은 URL 사용
```

### 지원 브라우저

| 브라우저 | 권장 버전 |
|---|---|
| Chrome | 최신 버전 권장 |
| Edge | 최신 버전 권장 |
| Firefox | 최신 버전 |
| Safari | 15 이상 |

> Internet Explorer는 지원하지 않습니다.

### 서버 상태 확인

접속이 되지 않는 경우, 관리자에게 서버 실행 여부를 확인 요청하세요.

- 백엔드 API 서버: `http://localhost:8000/health` 접속 시 `{"status":"ok"}` 응답 확인
- 프론트엔드 개발 서버: `http://localhost:5173` 접속 가능 여부 확인

## 3. 로그인 방법

### 로그인 화면

시스템 주소로 접속하면 로그인 화면이 표시됩니다.  
(이미 로그인된 경우 대시보드로 자동 이동)

```
┌───────────────────────────────────┐
│                                   │
│     Miracle-Cowork AgentPack      │
│     AI 기반 업무 자동화 플랫폼     │
│                                   │
│  이메일                            │
│  ┌───────────────────────────┐    │
│  │ example@company.com       │    │
│  └───────────────────────────┘    │
│                                   │
│  비밀번호                          │
│  ┌───────────────────────────┐    │
│  │ ••••••••                  │    │
│  └───────────────────────────┘    │
│                                   │
│  ┌───────────────────────────┐    │
│  │         로그인             │    │
│  └───────────────────────────┘    │
│                                   │
└───────────────────────────────────┘
```

### 로그인 단계

1. **이메일** 입력란에 등록된 이메일 주소를 입력합니다
2. **비밀번호** 입력란에 비밀번호를 입력합니다
3. **로그인** 버튼을 클릭합니다
4. 로그인 성공 시 대시보드 화면으로 이동합니다

### 계정 정보 안내

- 계정은 관리자가 생성합니다. 계정이 없으면 관리자에게 문의하세요
- 최초 관리자 계정은 시스템 초기 설정 시 생성됩니다

### 로그인 유지 시간

- 로그인 상태는 기본 **60분** 유지됩니다
- 60분 이후에는 자동으로 로그인 페이지로 이동합니다
- 작업 중 만료된 경우 재로그인 후 계속 사용할 수 있습니다

### 로그아웃

- 화면 우측 상단의 사용자 이름 옆 **로그아웃** 버튼을 클릭합니다
- 로그아웃 시 저장되지 않은 실행 결과는 사라지니 주의하세요

## 5. 8개 AgentPack 영역 설명

### 영역 구성 개요

| 순번 | 영역 | Agent 수 | 주요 활용 대상 |
|---|---|---|---|
| 1 | 정부 R&D | 10개 | 연구원, R&D 기획 담당자 |
| 2 | 회의/업무관리 | 7개 | PM, 팀 리더, 전 직군 |
| 3 | 연구개발 산출물 | 8개 | 개발자, 기술 PM |
| 4 | 지식/문서관리 | 7개 | 기획자, HR, 팀 리더 |
| 5 | 기획/전략 | 7개 | 전략기획, 경영진 |
| 6 | 제안/영업 | 7개 | 영업담당자, 제안 팀 |
| 7 | 개발협업 / Claude Code 연계 | 6개 | 개발자, 기술 문서 담당자 |
| 8 | 특허/기술사업화 | 5개 | 연구원, 기술이전 담당자 |

### 1. 정부 R&D 영역

정부 지원 사업 신청부터 연구 완료까지 전 단계 문서를 지원합니다.  
공고 분석 → 자격 검토 → 사업계획서 → 연구 수행 → 최종 보고로 이어지는 전 과정에 활용할 수 있습니다.

### 2. 회의/업무관리 영역

회의 전 준비부터 회의 후 정리까지, 팀의 일상적인 문서 작성을 자동화합니다.  
회의록, 액션 아이템, 주간 보고, 리스크 관리 등을 지원합니다.

### 3. 연구개발 산출물 영역

소프트웨어 개발 프로젝트의 필수 산출물을 체계적으로 생성합니다.  
요구사항 정의부터 테스트 케이스, WBS까지 개발 전 과정을 지원합니다.

### 4. 지식/문서관리 영역

조직 내 지식을 체계적으로 문서화하고 관리하는 데 활용합니다.  
업무 매뉴얼, 온보딩 가이드, 정책 문서, 품질 점검 등을 지원합니다.

### 5. 기획/전략 영역

사업 방향 설정과 의사결정에 필요한 전략 문서를 생성합니다.  
사업 기획서, 경쟁사 분석, SWOT 분석, IR 자료 초안 등을 지원합니다.

### 6. 제안/영업 영역

고객 대응과 영업 활동에 필요한 모든 문서를 지원합니다.  
제안서, 회사 소개서, 제품 소개서, PoC 제안서 등을 작성할 수 있습니다.

### 7. 개발협업 / Claude Code 연계 영역

개발팀의 기술 문서와 협업 문서 작성을 자동화합니다.  
Claude Code 사용자를 위한 프롬프트 생성, 코드 리뷰, 테스트 자동화 계획 등을 지원합니다.

### 8. 특허/기술사업화 영역

연구 성과물의 특허화와 사업화 전략 수립을 지원합니다.  
발명 정리부터 출원서 초안, 선행기술 비교, 사업화 전략까지 전 과정을 다룹니다.

## 7. Agent 실행 방법

### 실행 화면 구성

업무 영역에서 Agent를 선택하면 아래와 같은 실행 화면이 표시됩니다.

```
┌─────────────────────┬──────────────────────────────────────┐
│  [Agent 정보]       │                                      │
│  아이콘  Agent명     │   결과가 여기에 표시됩니다             │
│  출력 유형          │                                      │
│  Agent 설명         │   ✨                                 │
│                     │                                      │
│  ─────────────────  │   왼쪽 폼에 정보를 입력하고           │
│  [프로젝트 연결]    │   실행 버튼을 클릭하세요              │
│  ▼ 프로젝트 선택    │                                      │
│                     │                                      │
│  ─────────────────  │                                      │
│  [입력 정보]        │                                      │
│                     │                                      │
│  항목 1 *           │                                      │
│  [입력란]           │                                      │
│                     │                                      │
│  항목 2             │                                      │
│  [입력란]           │                                      │
│                     │                                      │
│  [■ Agent명 실행]   │                                      │
└─────────────────────┴──────────────────────────────────────┘
```

### 단계별 실행 방법

**1단계: 프로젝트 연결 (선택 사항)**

실행 결과를 특정 프로젝트에 연결하여 저장하려면 프로젝트를 미리 선택합니다.

1. "프로젝트 연결" 드롭다운을 클릭합니다
2. 저장할 프로젝트를 선택합니다
3. 프로젝트 없이 실행만 하려면 "프로젝트 선택 안 함" 유지

**2단계: 입력 정보 작성**

각 항목에 필요한 내용을 입력합니다. 입력값 작성 방법은 [8장](#8-입력값-작성-방법)을 참고하세요.

**3단계: 실행 버튼 클릭**

1. 입력 완료 후 하단의 **[Agent명 실행]** 버튼을 클릭합니다
2. 실행 중에는 버튼이 "실행 중..." 상태로 변경되고 스피너가 표시됩니다
3. 실행 완료 후 우측 결과 영역에 문서가 표시됩니다

> 실행 시간은 Mock 모드에서 보통 1~3초, LLM 모드에서 5~30초 소요됩니다.

## 8. 입력값 작성 방법

### 입력 항목 유형

| 유형 | 표시 방식 | 작성 방법 |
|---|---|---|
| 텍스트 입력 | 한 줄 입력란 | 짧은 단어, 문장, 날짜 등 간결하게 입력 |
| 텍스트 영역 | 여러 줄 입력란 | 상세 내용, 목록, 문단 형식으로 자유롭게 입력 |
| 선택 목록 | 드롭다운 | 제공된 옵션 중 하나를 선택 |

### 필수·선택 항목 구분

- 항목명 옆에 빨간색 `*` 표시가 있으면 **필수 항목**입니다
- 필수 항목을 비워두고 실행하면 오류 메시지가 표시됩니다

### 입력값 작성 팁

**구체적으로 작성할수록 결과 품질이 높아집니다.**

| 항목 예시 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 사업명 | 우리 사업 | AI 기반 중소기업 업무 자동화 SaaS 플랫폼 |
| 연구 기간 | 1년 | 2026년 6월 ~ 2027년 5월 (12개월) |
| 핵심 기술 | AI | 자연어 처리(NLP) 기반 문서 자동 생성 기술 |
| 목표 시장 | 기업 | 연매출 50억 미만 중소기업·스타트업 (국내 약 80만 개사) |

### 텍스트 영역 작성 예시

여러 항목이 있는 경우 줄바꿈이나 번호 목록으로 구분하면 더 나은 결과가 나옵니다.

```
[나쁜 예]
우리 회사는 AI 관련 기술을 보유하고 있으며 B2B 시장을 타겟으로 합니다

[좋은 예]
- 주요 기술: GPT 기반 문서 자동화, OCR 연동 데이터 추출
- 기업 규모: 임직원 12명, 설립 3년차
- 타겟 고객: 중소기업 및 스타트업 (B2B)
- 보유 특허: AI 문서 분류 알고리즘 특허 1건
```

### 플레이스홀더(안내 문구) 활용

각 입력란에는 예시 문구가 연하게 표시됩니다. 이를 참고하여 형식에 맞게 입력하세요.

## 9. 실행 결과 확인 방법

### 결과 화면 구성

```
┌──────────────────────────────────────────────────────┐
│  [완료 ✓]  [✓ 저장 완료]  [✓ 복사됨]                 │
│                                                      │
│  ┌────────────────────────────────────────────────┐  │
│  │  # 사업계획서                         [복사][저장]│  │
│  │                                                │  │
│  │  ## 1. 사업 개요                               │  │
│  │  본 사업은 AI 기반 업무 자동화 플랫폼으로...     │  │
│  │                                                │  │
│  │  ## 2. 기술 현황                               │  │
│  │  | 기술명 | 완성도 | 특허 |                    │  │
│  │  |--------|--------|------|                    │  │
│  │  | NLP    | 80%    | 출원 |                    │  │
│  │                                                │  │
│  └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

### 결과 확인 방법

1. **상태 배지 확인**: 결과 상단에 "완료 ✓" 배지가 표시되면 정상 생성된 것입니다
2. **내용 스크롤**: 긴 문서는 스크롤하여 전체 내용을 확인합니다
3. **Markdown 렌더링**: 제목, 소제목, 표, 목록 등이 서식이 적용된 형태로 표시됩니다

### 결과 복사

- 결과 영역 우측 상단의 **복사** 버튼을 클릭합니다
- "✓ 복사됨" 표시 확인 후 원하는 곳에 붙여넣기(`Ctrl+V`) 합니다
- 노션, 워드, 이메일 등 어디에나 붙여넣을 수 있습니다

## 10. 결과 저장 방법

저장 기능은 **로그인한 사용자만** 사용할 수 있습니다.

### 저장 단계

1. Agent 실행 완료 후 결과가 표시된 상태에서
2. (선택) 좌측 "프로젝트 연결" 드롭다운에서 저장할 프로젝트를 선택합니다
3. 결과 영역 우측 상단의 **저장** 버튼을 클릭합니다
4. "✓ 저장 완료" 배지가 표시되면 저장이 완료된 것입니다

### 저장 정보 안내

| 저장 항목 | 내용 |
|---|---|
| 제목 | `[Agent명] 저장일시` 형식으로 자동 생성 |
| 내용 | 실행 결과 전체 (Markdown 형식) |
| 프로젝트 | 선택한 프로젝트에 연결 (선택 시) |
| 저장자 | 로그인한 계정으로 자동 기록 |

> 저장 버튼은 한 번 저장 후 "✓ 저장 완료"로 변경되어 중복 저장을 방지합니다.  
> 동일한 결과를 다시 저장하려면 Agent를 다시 실행하세요.

## 11. 저장 문서 조회 방법

### 저장 문서 탭 화면

## 12. Markdown 다운로드 방법

### 다운로드 방법 1: 프로젝트 저장 문서 탭

1. 프로젝트 상세 → 저장 문서 탭으로 이동
2. 다운로드할 문서의 **[↓ MD]** 버튼을 클릭합니다
3. `[문서 제목].md` 파일이 자동으로 저장됩니다

### 다운로드 방법 2: 문서 상세 화면

1. 저장 문서 목록에서 문서를 클릭하여 상세 화면으로 이동합니다
2. 화면 우측 상단의 **[↓ MD 다운로드]** 버튼을 클릭합니다
3. `[문서 제목].md` 파일이 자동으로 저장됩니다

### 다운로드된 파일 활용 방법

| 도구 | 활용 방법 |
|---|---|
| VS Code | `.md` 파일 열기 후 미리보기(`Ctrl+Shift+V`) |
| Typora | `.md` 파일을 바로 열면 렌더링된 문서로 표시 |
| Obsidian | Vault에 파일 저장 후 열기 |
| Notion | "가져오기" → Markdown 선택 |
| 워드(Word) | Pandoc 또는 온라인 변환 도구 활용 |
| 이메일 공유 | `.md` 파일 첨부 또는 내용을 복사하여 붙여넣기 |

> Word(.docx) / PDF 직접 다운로드 기능은 향후 업데이트 예정입니다.

## 13. LLM 모드와 Mock 모드 차이

### 모드 비교

| 항목 | Mock 모드 (기본) | LLM 모드 |
|---|---|---|
| **동작 방식** | 사전 작성된 템플릿 출력 | Claude AI가 입력값 기반으로 실시간 생성 |
| **API Key 필요** | 없음 | 필요 (Anthropic API Key) |
| **결과 품질** | 표준 수준 (고정 템플릿) | 고품질 (입력값 반영) |
| **응답 속도** | 1~3초 | 5~30초 |
| **비용** | 무료 | API 사용량에 따른 과금 |
| **입력값 반영** | 부분 반영 | 입력값 전체 반영 |

### 현재 동작 모드 확인 방법

관리자에게 현재 설정된 모드를 확인 요청하세요.  
Mock 모드로 동작 중인 경우 결과가 템플릿 형식임을 확인할 수 있습니다.

### Mock 모드에서도 유용하게 사용하는 방법

1. 문서 **구조와 목차**를 참고 자료로 활용합니다
2. 생성된 내용을 **기반으로 수정**하여 완성도를 높입니다
3. 복사 후 워드·노션에서 **직접 편집**합니다

### LLM 모드 전환 요청

Claude API 연동이 필요한 경우 관리자에게 아래를 요청하세요:
- Anthropic API Key 발급 및 서버 설정
- `AGENT_RUNNER_MODE=llm` 환경 변수 설정
- 서버 재시작

## 14. 자주 발생하는 오류와 해결 방법

### 오류 1: 로그인이 되지 않습니다

| 증상 | 해결 방법 |
|---|---|
| "이메일 또는 비밀번호가 올바르지 않습니다" | 이메일·비밀번호 재확인. 대소문자 주의 |
| 로그인 버튼 클릭 후 반응 없음 | 백엔드 서버(포트 8000) 실행 여부 확인 |
| 계정이 없다는 메시지 | 관리자에게 계정 생성 요청 |

### 오류 2: Agent 실행 중 오류가 발생합니다

| 증상 | 해결 방법 |
|---|---|
| "Agent 실행 중 오류가 발생했습니다" | 백엔드 서버 실행 여부 확인 후 재시도 |
| "필수 입력 항목을 채워주세요" | `*` 표시 항목 모두 입력 후 재실행 |
| 실행 버튼 클릭 무반응 | 브라우저 새로고침 후 재시도 |

### 오류 3: 저장이 되지 않습니다

| 증상 | 해결 방법 |
|---|---|
| "저장 중 오류가 발생했습니다" 배지 표시 | 로그인 상태 확인. 만료 시 재로그인 |
| 저장 버튼이 보이지 않음 | Agent를 실행하여 결과가 표시된 후 시도 |
| "✓ 저장 완료" 상태로 저장 불가 | 이미 저장됨. 재저장 시 Agent 다시 실행 |

### 오류 4: 세션이 만료되었습니다

| 증상 | 해결 방법 |
|---|---|
| 로그인 페이지로 자동 이동 | 재로그인 후 작업 계속 진행 |
| 작업 중 갑자기 로그인 화면 | 60분 세션 만료. 재로그인 필요 |

### 오류 5: 다운로드가 되지 않습니다

| 증상 | 해결 방법 |
|---|---|
| 다운로드 버튼 클릭 후 파일 없음 | 브라우저 다운로드 차단 설정 확인 |
| "다운로드 중 오류가 발생했습니다" | 로그인 상태 확인 후 재시도 |

## 15. FAQ

**Q. 계정은 어떻게 만드나요?**  
A. 계정 생성은 관리자 권한이 필요합니다. 시스템 관리자에게 이메일·이름·역할을 알려주고 계정 생성을 요청하세요.

**Q. 비밀번호를 잊어버렸습니다.**  
A. 현재 비밀번호 셀프 재설정 기능은 미구현 상태입니다. 관리자에게 비밀번호 초기화를 요청하세요.

**Q. 생성된 문서의 내용이 항상 비슷합니다.**  
A. Mock 모드에서는 입력값과 무관하게 유사한 템플릿이 출력됩니다. Claude API가 연동된 LLM 모드에서는 입력값을 완전히 반영한 문서가 생성됩니다. 관리자에게 LLM 모드 전환을 요청하세요.

**Q. 여러 Agent를 연속으로 실행할 수 있나요?**  
A. 네. 각 Agent를 순서대로 실행하고 저장하면 됩니다. 같은 프로젝트에 연결하면 관련 문서들이 한 곳에 모입니다.

**Q. 저장한 문서를 수정할 수 있나요?**  
A. 현재 버전에서는 저장 후 직접 수정 기능이 없습니다. 다운로드 후 외부 편집기에서 수정하거나, Agent를 다시 실행하여 새 버전을 저장하세요.

**Q. 문서를 삭제할 수 있나요?**  
A. 문서 작성자 본인 또는 관리자(admin)·매니저(manager)만 삭제 가능합니다. UI 삭제 버튼은 향후 업데이트 예정이며, 현재는 API로만 삭제 가능합니다.

**Q. 한 번에 여러 프로젝트에 저장할 수 있나요?**  
A. 한 번 실행 시 하나의 프로젝트에만 저장됩니다. 다른 프로젝트에도 저장하려면 Agent를 다시 실행하여 다른 프로젝트를 선택하세요.

**Q. Word나 PDF로 받을 수 없나요?**  
A. 현재는 Markdown(.md) 다운로드만 지원합니다. 다운로드된 파일을 Pandoc, Typora, Notion 임포트 등으로 변환할 수 있습니다. 직접 변환 기능은 향후 업데이트 예정입니다.

**Q. 모바일에서도 사용할 수 있나요?**  
A. 현재 모바일 최적화는 되어 있지 않습니다. PC 브라우저 사용을 권장합니다.

## 16. 부록: 권장 사용 시나리오

### 시나리오 1: 정부 R&D 과제 신청 준비

**상황**: 중소기업 R&D 기획팀이 정부 지원 사업 신청서를 준비합니다.

```
1단계: [정부 R&D 공고 분석] 실행
   → 공고문 붙여넣기 → 적합도·전략 분석 결과 저장

2단계: [신청 자격 검토] 실행
   → 공고 조건 + 기업 현황 입력 → 자격 충족 여부 확인 저장

3단계: [사업계획서 작성] 실행
   → 사업명·기술·목표 입력 → 초안 저장

4단계: [연구비 산정표] 실행
   → 연구 기간·항목별 예산 입력 → 표 저장

5단계: [제출서류 체크리스트] 실행
   → 전체 준비 현황 점검
```

→ 모든 문서를 하나의 프로젝트("○○과제 신청")에 저장하여 통합 관리

---

### 시나리오 2: 주간 팀 회의 운영

**상황**: PM이 매주 반복되는 회의 문서를 자동화합니다.

```
회의 전: [업무지시문서] 실행 → 이번 주 업무 분배 공지 발송

회의 중: 노트 앱에 키워드만 메모

회의 후: [회의록 작성] 실행 → 메모 붙여넣기 → 완성된 회의록 저장
         [To-do 정리] 실행 → 회의록 기반 액션 아이템 추출 저장
         [주간업무보고서] 실행 → 이번 주 현황 보고서 저장
```

→ 주간 보고서를 MD 다운로드 후 이메일 첨부로 상위 보고

---

### 시나리오 3: 신규 서비스 제안서 작성

**상황**: 영업팀이 잠재 고객에게 제안서를 준비합니다.

```
1단계: [영업 회의 준비] 실행 → 고객 미팅 전 체크리스트 확인

2단계: [회사소개서 작성] 실행 → 우리 회사 소개 문서 저장

3단계: [제품소개서] 실행 → 제품·서비스 특징 설명서 저장

4단계: [영업 제안서 작성] 실행 → 고객 맞춤형 제안서 초안 저장

5단계: 각 문서 MD 다운로드 → 편집 후 PDF 변환 → 고객 발송
```

---

### 시나리오 4: 소프트웨어 개발 프로젝트 킥오프

**상황**: 개발팀이 신규 프로젝트 착수 문서를 준비합니다.

```
1단계: [요구사항 정의서 작성] 실행 → 시스템 요구사항 정의

2단계: [기능명세서 작성] 실행 → 상세 기능 명세

3단계: [DB 설계 내역] 실행 → 데이터베이스 초안

4단계: [API 명세서] 실행 → REST API 명세

5단계: [개발 WBS] 실행 → 전체 일정 및 담당자 배분

6단계: [테스트케이스] 실행 → 기능 테스트 시나리오
```

→ "○○프로젝트 킥오프" 프로젝트에 6개 문서 저장 및 팀 공유

### 시나리오 5: 특허 출원 준비

**상황**: 연구원이 개발한 기술을 특허로 출원하려고 합니다.

```

2단계: [선행기술 비교] 실행 → 기존 특허와 차별성 분석

3단계: [특허출원서 초안] 실행 → 청구항·명세서 초안 작성

4단계: [사업화 전략] 실행 → 특허 활용 사업화 방안 수립
```

→ 모든 문서를 MD 다운로드 후 변리사에게 전달하여 정식 출원 진행
